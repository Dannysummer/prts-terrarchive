# 本地工具

## 本地资料目录

本地 release 同时包含明日方舟与终末地资料分区。Agent 不需要使用内部 pack 名；调用时使用统一的 `games`、`resource_types`、`content_types` 和 `collection_names`。

| `resource_type` | 本地内容 | 来源／证据性质 | 适合的问题 |
| --- | --- | --- | --- |
| `story` | 主线、活动及其他剧情篇章 | 官方游戏剧情原文 | 台词、说话人、场景、行动、剧情细节和逐行引用 |
| `operator_record` | 干员密录正文，已绑定所属角色 | 官方游戏剧情原文 | 某角色密录经历、密录台词与场景 |
| `character_profile` | 干员档案、招聘合同、潜能与信物 | 官方结构化角色资料 | 身份、履历、体检、档案陈述和招聘描述 |
| `character_module` | 模组故事与模组文案 | 官方结构化角色资料 | 人物补充经历、物品故事和能力背景 |
| `character_voice` | 干员语音文本 | 官方结构化角色资料 | 语音原句、称呼、态度与罗德岛日常表达 |
| `character_skin` | 时装文案 | 官方结构化角色资料 | 服装、时期、场景和附带设定 |
| `character_bundle` | 指定角色的档案、模组、语音和密录合集 | 查询便利类型，不是新的资料来源 | 不确定信息落在哪一种角色官方资料时一次限定角色搜索 |
| `character_wiki` | 规范角色 Wiki | 审核／整理性资料 | 生平、关系、剧情高光、战斗表现和参加活动清单 |
| `story_wiki` | 活动、主线章节或密录 Wiki | 审核／整理性资料 | 剧情总结、关键人物、角色作用和活动导航 |
| `character_activity_wiki` | 角色×活动辅助页 | 整理性辅助资料 | 某角色在某活动中的过程、关系和高光线索 |
| `reviewed_wiki` | 上述全部 Wiki 的并集 | 查询便利类型 | 确实需要跨 Wiki 类型搜索时使用；通常优先选择窄类型 |
| `terra_journey` | 《大地巡旅》的可定位文本投影 | 出版设定资料的本地整理投影 | 地域、历史、种族和世界观线索；引用时与游戏原文区分 |
| `entity_profile` | 人物、组织、地点等实体概述与历史摘要 | 审核实体资料／检索投影 | 快速了解实体、别名、背景和跨资料入口 |
| `reference` | 活动时间线、泰拉年表、别名及来源绑定等 | 整理性检索辅助资料 | 年代、事件先后、活动范围、别名消歧与出处反查 |

选择原则：逐字事实优先官方原文或官方结构化资料；概括、清单和导航可使用 Wiki、实体资料与时间线；不同层冲突时回到官方原文。`character_bundle` 和 `reviewed_wiki` 只是并集快捷方式，能确定窄类型时不要先搜并集。

当前本地包不包含云端图谱、PostgreSQL 向量候选、经典检索结果或旧版中间数据。这些能力由 `cloud_search` 提供，不能把本地零命中解释成云端也没有相关资料。

## corpus_search

把它当作懂 PRTS 资料结构的 grep：`query` 是连续字面串，活动、篇章、角色、说话人、实体、资料类型和 Wiki 字段是正交范围。同一字段内 OR，不同字段间 AND；`context_terms` 例外，其中每一项都必须在主命中附近出现。

- `character_names` 表示资料属于谁；`speakers` 表示谁亲口说话；`entity_names` 表示哪一实体出现在命中或结构化关联中。
- 省略 query，只给资料归属条件时返回资料目录；省略 query 且选择一个 Wiki 字段时返回字段完整内容。
- 默认 literal。regex 只用于确有必要的模式搜索；不支持反向引用和环视，也不会失败后自动改成 literal。
- 原文命中固定返回 passage 外侧上下各一行。搜索预览宽度、每页文档数和每篇 passage 数不能调整；结果太多时增加过滤，或保留原搜索条件并提交返回的自然标题锚点 `next_after` 继续。不要把内部 cursor 写进新请求。
- `entity_profile` 命中优先返回实体概述与历史摘要，不显示底层 JSON 骨架；实体资料使用“名称 / 实体资料”自然标题，与同名 Wiki 消歧。
- 官方原文精确命中可直接引用。目录、标题、实体投影和整理性资料仍只是相应等级的入口或证据。

## corpus_read

- `title + line` 扩大命中上下文，按需设置 before/after。
- `title + section` 读取 Wiki 字段。
- `title + mode="document"` 分页阅读全文。
- 继续阅读时直接使用结果给出的完整 `title` 与下一行 `line`，通常形式为 `title + line + before:0 + after:100`。不要复制、生成或解释内部 cursor。
- 已经存在于旧会话中的 cursor 仍可使用；兼容调用允许同时附带对应的完整 `title`、`mode="document"`，以及新的 `max_lines` / `max_chars`，但新一轮读取不得主动采用这种形式。
- 只使用搜索或云端结果给出的完整自然语言标题，不使用 ref、路径、document ID 或短代号。
- 只返回明确请求的原文、Wiki 字段或文档分页，不会自动附带剧情总结和活动时间线。

## timeline_search

- 可组合活动、年份和实体；不同维度取交集，实体名会自动展开别名。
- 检索结果按标准化时间从早到晚稳定排列；相同事件 ID 只返回一次，并在同一条结果中列出全部关联活动。
- 主线章节号可直接使用 `query="第17章"`，也可放入 `activity_names=["第十七章"]`；工具会映射到对应活动展示名。
- 时间线是整理性证据。其出处标记只用于工具反查，不写入最终回答。
